# Demo Scenario 실행 안내

Demo Mode는 서버·차량·네트워크 없이 MODO의 핵심 흐름을 재현합니다. 모든 조작은 실제 도메인 명령(`JourneyCommand`)으로 처리되어 ViewModel과 그룹 상태가 실제로 바뀝니다. **차량 B·C의 행동, 모든 차량의 위치, 다른 차량의 경로 적용 결과는 시뮬레이션**이며 화면에 `DEMO · Simulated vehicle data`가 항상 표시됩니다.

## 시작

1. 앱 실행 → Welcome 화면에서 **Demo Experience**
2. 화면 오른쪽 아래: 현재 장면 표시, **DEMO**(Demo Controller 열기), **다음 장면**

## 장면 (Demo Controller와 동일)

| 장면 | 실행되는 명령 (실제 상태 변경) | 화면 |
|---|---|---|
| Scene 1 · 출발 | Reset: 그룹 "강릉 여행", A(3명)·B(3명)·C(2명) = 8명, 위치 공유 동의(시뮬레이션), 이동 중 | Journey Room |
| Scene 2 · 휴식 요청 | 차량 B 음성 입력 재현 "우리 잠깐 쉬었다 가자." → `CreateRequest` → `REST_REQUEST` | Mobility Intent: 인식 결과 "휴식 요청", 그룹 알림 "차량 B가 휴식을 요청했어요.", 다음 행동 "합류 장소를 정할까요?" |
| Scene 3 · 합류 제안 | A가 횡성휴게소 `ProposeRendezvous`, B `RespondToProposal(동의)` | Smart Rendezvous: A 동의 · B 동의 · C 대기 |
| Scene 4 · 합의 | C 동의 → 제안 `APPROVED` | Group Route Action: "그룹 합의 완료", 아직 적용 0/3 |
| Scene 5 · 경로 적용 | `DispatchNavigation` → A(내 차량 내비게이션)·B 적용, C 운전자 확인 대기 | 실제 적용 2/3, C "운전자 확인 대기" |
| Scene 6 · 합류 실패 | A·B 횡성휴게소 도착 확인, C는 휴게소를 지나친 위치 → `OpenRecovery(MISSED_RENDEZVOUS)` | Group Recovery: "차량 C가 기존 합류 장소에 합류하지 못했습니다." / "새로운 합류 장소를 정할까요?" / 추천: 평창휴게소 |
| Scene 7 · 재합류 | 재합류 제안(계획 #2, 이전 계획 #1 대체) → B·C 동의 → 경로 적용(C 포함 3/3) | "새로운 합류 계획이 확정되었어요." / "각 차량이 안전한 경로로 이동합니다." / 기존 계획 #1 취소선 |
| Scene 8 (1/2) · 합류 | 세 차량 평창휴게소 도착 확인 | Journey Room "모두 합류했어요." |
| Scene 8 (2/2) · 도착 | 세 차량 강릉역 도착 확인(사용자 확인) → `COMPLETED` | Journey Completed |

- 발표자가 화면에서 차량 A의 행동(합류 장소 정하기, 동의, 경로 변경 요청, 재합류 제안 등)을 직접 해도 됩니다. 이후 "다음 장면"을 누르면 남은 단계만 실행됩니다.
- 장면 목록을 탭하면 **Reset 후 처음부터 해당 장면까지 순서대로** 실행합니다. 데모 시계와 id가 고정되어 있어 매번 같은 결과가 나옵니다(자동 테스트로 검증).

## Reset Demo

Demo Controller 상단 **Reset Demo** 또는 완료 화면의 **Reset Demo**. 그룹 상태, id 순서, 데모 시계, 네트워크 끊김/실패 설정, 화면 단계가 모두 최초 상태로 돌아갑니다. Demo Mode에서만 표시됩니다.

## 테스트 조작 (Demo Controller)

| 버튼 | 동작 |
|---|---|
| C 동의 / C 거절 | 진행 중인 제안에 C가 응답 (거절 시 제안 REJECTED, 요청은 다시 열림) |
| C 운전자 확인 → 적용 | C의 NavigationAction `REQUESTED` → 차량 C 단말 시뮬레이션이 `APPLIED` 보고 |
| C 적용 실패 | `FAILED` + 오류 메시지 → "실패 및 재시도 필요", 재시도 버튼 |
| C 응답 없음 | `UNKNOWN`(응답 시간 초과) |
| C 합류 실패 발생 | `OpenRecovery(MISSED_RENDEZVOUS)` + 다음 휴게소 추천 |
| B 음성 요청 재현 / B 동의 | 차량 B 행동 |
| B 연결 끊김/복구 | "연결 끊김" 표시 토글 |
| B 위치 갱신 중단 | 데모 시계를 2분 진행하고 B만 위치를 보내지 않음 → "위치 갱신 중단 · 마지막 위치 HH:mm" |
| 네트워크 끊김/복구 | 모든 명령이 네트워크 오류로 실패 → 경고 배너 + "다시 시도" (같은 commandId로 재전송) |
| 음성 인식 실패 / 인식 불가 명령 | 다음 음성 입력을 실패 또는 "라디오 볼륨 좀 올려줘"(분류 불가)로 설정 |
| 내 경로 적용 실패 | 내 차량 다음 내비게이션 요청을 실패로 처리 |
| 내 차량(A)에 실제 Pleos NaviHelper 사용 | 켜면 내 차량 경로 적용만 실제 NaviHelper로 요청 (Pleos Connect 환경 필요). 다른 차량은 계속 시뮬레이션 |
