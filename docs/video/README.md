# 시연 영상 제작 자료 (약 90초)

이 개발 환경에는 영상 인코딩 도구(ffmpeg)가 없어 **MP4는 만들지 않았습니다.** 아래 녹화 순서, 자막(`subtitles_ko.srt`), 내레이션, 편집 가이드로 제작할 수 있습니다. 90초는 편집 목표이며 공식 필수 규격이 아닙니다.

## 원칙
- 앱의 **실제 실행 화면**만 사용합니다 (목업/합성 화면 금지).
- Demo Mode 장면에는 화면의 `DEMO · Simulated vehicle data` 표시를 가리지 말고, 편집 시 첫 데모 장면에 "시뮬레이션 데이터로 시연합니다" 자막을 함께 넣습니다.
- 실제로 동작을 확인한 SDK 연동은 NaviHelper 경로 요청(Pleos 내비게이션 앱 안내 시작), FusedLocation 수신, STT/TTS 초기화까지입니다. **음성 인식 결과나 TTS 음성이 실제 SDK에서 나온 것처럼 편집하지 않습니다.** 데모의 음성 안내는 화면 자막("음성 안내 시뮬레이션")입니다.
- 개인정보·서명 키·서버 주소가 화면에 나오지 않게 합니다 (데모 모드는 초대 코드도 표시하지 않음).

## 녹화 준비
1. Pleos Connect Emulator v2.1.0 실행 (권장: 외장 GPU PC에서 `-gpu host`; 이 저장소 검증 환경은 Apple Silicon에서 `-gpu swangle_indirect`)
2. `adb install apk/정지원_MODO_release.apk`
3. 녹화: 에뮬레이터 Extended Controls > Record and Playback, 또는
   `adb shell screenrecord --bit-rate 12000000 /sdcard/modo_1.mp4` (최대 3분, 장면별로 나눠 녹화 권장)
4. 앱 실행 → **Demo Experience** → 오른쪽 아래 **DEMO** → **Reset Demo**

## (선택) 실제 SDK 연동 컷 — 5초 내외
Demo Controller에서 **내 차량(A)에 실제 Pleos NaviHelper 사용**을 켠 뒤 Scene 5를 실행하면 Pleos 내비게이션 앱이 실제로 횡성휴게소 경로 안내를 시작합니다 (`docs/screenshots/emulator/e09_navihelper_route_in_pleos_navigation.png`). 이 컷에는 "Pleos NaviHelper SDK로 실제 경로 요청" 자막을 넣을 수 있습니다. 단, 이 검증 환경에서는 내비게이션 지도 영역이 검게 보였으므로(외장 GPU 없는 에뮬레이터 제약) GPU 환경에서 다시 녹화하는 것을 권장합니다.

## 편집 가이드
- 해상도: 녹화 2560×1440 → 출력 1920×1080, 30fps. 앱 영역(오른쪽 창)만 크롭해 확대해도 됩니다.
- 장면 전환: 0.3초 크로스페이드. 과도한 모션 그래픽은 피합니다 (앱 콘셉트와 일치).
- 자막: `subtitles_ko.srt`를 기준으로 하고, 실제 녹화 길이에 맞춰 시간을 조정합니다. 굵은 산세리프, 하단 중앙, 앱의 하단 자막·DEMO 표시와 겹치지 않게 위로 띄웁니다.
- 음악: 저작권 문제가 없는 잔잔한 곡, 내레이션 구간 -18dB 이하.
